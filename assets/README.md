## 风格基准

**设置卡片那张**：拍**配置表单本体** —— 从插件标题下方到保存按钮：四组字段行（默认全展开）、状态徽标、说明行、**唯一的保存按钮**。
没有卡片外框、没有折叠头，「放弃」按钮也不存在；不拍浏览器标签。

**Plugins 列表那张**（文件名仍是 `settings-cards-position*.png`）：目的是回答「长在哪、与谁并排」，所以拍 **Plugins 页的列表视图** —— 左侧栏（**收起态**，见下条）+ Official / Installed 两组列表，`ds-balance` 在已安装里可见。
**列表与详情是同一页互斥的两个视图**，一张图塞不下「列表 + 配置表单」：配置表单本体由 `settings-card*.png` 承担（见上）。这张**不用点进详情页**。
它必然带进已装插件的名字（官方的与第三方的），那是要交代的上下文，不是隐私问题：插件页里没有对话内容，侧栏收起后也不带会话标题与工作区名。

**画面里带左侧栏的整屏 / 宽幅图，按快门前一律收起左侧栏**：展开的侧栏列的是维护者真实的**会话标题与工作区名** —— 那是别人的工作内容，不是装饰，门面图不能带出去。
收起状态下点不到 `Plugins`，所以顺序固定：**展开导航 → 走到画面 → 收起侧栏 → 按快门**（[AGENTS.md](AGENTS.md) 第 4 步）。

**左边栏那张**：目的是回答「这东西长在哪、长什么样」，所以必须带上下文 ——
左边栏底部那一叠条目（本条目 + 下方邻居「设置」）+ 展开的浮层，右侧留出一小条聊天区。
**它是上面那条规则的唯一例外**（主体就是侧栏本身，收了就没了）：隐私改由裁剪切掉 —— **取景顶端一律压在浮层 / 底部条目那一叠的上沿**，把上方的工作区名与会话标题整段剔出画面。
**隐私优先于输入框** —— 宁可不要输入框，也不能露标题；因此这张常常没有输入框，那是接受的代价。
**边缘是：看得出在左下角，但不拍整屏。**

**隐私是硬要求**：拍左边栏那张之前**必须开一个新会话**（[AGENTS.md](AGENTS.md) 第 2 步）。
停在旧会话上会把正在进行的对话连同工具调用一起拍进聊天区 —— 那是别人的工作内容，不是装饰；新会话只保证「没有工作文字」，侧栏标题得靠上面的裁剪剔掉。

其余：

- **图里不许出现真实凭据、真实 Base URL**。凭据行只允许出现状态徽标；只读行的输入框是空的。
- 余额数字是真实值，会随时间变 —— 重截必然与旧图不同，这是预期，不要为了「对齐」去 P 图。
- **整屏图不要设置 viewport**：用自然视口拍，物理产物自然就是 **2449x1223**（CSS 视口 1484x741 × dpr 1.65）。**`setViewportSize(2449, 1223)` 是错的** —— 它把 dpr 压成 1，界面只剩约 60%。只有拍长元素时才临时调高度，**拍完还原**；元素图的像素尺寸由内容决定，别照抄旧图的数字。

## 与发版的关系

- 图**不进 npm 包**：[package.json](../package.json) 的 `files` 里没有 `assets`。
  改图不改产物，[release-guard.mjs](../scripts/release-guard.mjs) 把它归在「不影响产物」那一档。
- 但图是门面的一部分：改了卡片外观却不重截，README 上挂的就是一张与界面不符的图。
