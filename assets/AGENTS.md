## 什么时候必须重截

判据是「卡片渲染出来的东西有没有变」，不是「改了哪个文件」。
与 [release-guard.mjs](../scripts/release-guard.mjs) 同一种分工：它只判路径，行为等价的改动交给人回答。

必须重截：

- [locales.ts](../src/client/locales.ts) 两份字典的**文案值**（中英任一）
- [BalanceSettingsCard.tsx](../src/client/settings/BalanceSettingsCard.tsx) 的 **JSX 结构**：字段增删、顺序、按钮、状态行
- [fields.tsx](../src/client/settings/fields.tsx) 的**控件形态**：只读行、折叠头、二级 details
- 三个 `*.module.css` 的**样式值**：字号、行高、间距、令牌、布局
- 卡片**可见状态**的语义：未保存标记、凭据行的四档徽标、只读行留空、失败诊断
- **左边栏那张另有判据**：[SidebarBalance.tsx](../src/client/sidebar/SidebarBalance.tsx) 的行结构、
  [BalancePopover.tsx](../src/client/sidebar/BalancePopover.tsx) 的三行与状态行，
  以及 [PercentRing.tsx](../src/client/sidebar/PercentRing.tsx) 的**弧长与中心符号** ——
  弧长现在表达比例，余额一变图就变，这是它的正常状态。

不必重截：

- 类型与注释（只活在编译期）
- 行为等价的内部重构：抽常量、改名、等价重写
- `README` / `AGENTS` / 测试 / 构建配置
- `inject`、注册 key、`dsh.client.*`：它们坏了是「卡片装不上」，不是「图不准」

拿不准时按「必须重截」办：图的成本低于一张与界面不符的图。

## 完成定义

- 改渲染面的改动，**要么同批带重截图，要么在 commit body 里写明为什么不重截**。
- 图与文案分成两个提交，会留下「文案已改、README 里的图还是旧的」的窗口。

## 怎么截

截图会改**全局设置**（语言等），所以第 0 步是问，不是动手。

0. **先问再动**，问的时候说清三件事，再等维护者确认：
   - 要占用浏览器几分钟；
   - 会临时切界面语言，结束切回；
   - **截图期间请别改语言 / 主题 / 模型等全局设置** —— 它们直接进画面。
1. **用自己的标签页，不动维护者的标签页**：agent 端点新开一个页面打开 GUI 即可，结束时关掉它。
2. **开一个新会话**，再按 [风格基准](README.md#风格基准) 把画面摆到位；摆好后**不再动任何别的东西**。
   - **这一步是隐私要求，不是可选项**：不新开会话，聊天区里就是正在进行的那段对话，
     连工具调用一起进图。拍左边栏那张时尤其致命 —— 它必然带一条聊天区。
   - 新会话的输入框停在**屏幕中央**（不是底部），所以左边栏那张的取景要往上延到输入框，
     代价是会带进侧栏的会话标题。要更干净就把取景压到浮层顶部以下，代价是没有输入框。
3. 打开「设置 → 插件 → 插件配置」，**展开本卡片的四组折叠**（连接 / 展示 / 阈值 / 刷新），
   滚到卡片完整可见（底部「放弃 / 保存」必须在图内）。
   连接组里的二级「自定义设置」**保持收起** —— 那是高级用户的路径，展开它会让图里出现一屏凭据字段。
4. **开关状态照现状拍**：拨它会带出「未保存」标记，真保存又改了维护者的真实配置。
5. 先拍中文存成 `settings-card.png`，再临时把界面语言切成 English 拍 `settings-card_en.png`，然后**把语言切回原状**。
   左边栏那张同理：`sidebar-popover.png` / `sidebar-popover_en.png`，**同一次会话里一起拍**，
   两张取景完全一致，否则并排看会发现构图不同。
6. **交还**：关掉设置面板 → 关掉自己的标签页 → 把当前会话切回维护者原来那个 → 告诉他可以用了。

拍完把两张图覆盖进本目录，**文件名不许改** —— 根 README 与 README_en 按名引用。

## 已知约束

- 截图工具给的是显式 viewport，拿不到整屏；基准因此不写死像素（见 [README.md](README.md)）。
- **卡片比设置对话框的滚动容器高**，容器会把下半截裁掉：直接对卡片做 `locator.screenshot()` 会拍到容器外的页面，
  出来是一张「上半截是卡片、下半截是聊天记录」的废图。实拍顺序必须是：
  先把卡片到 `body` 之间的祖先逐个解除裁剪（`overflow: visible` + `max-height: none`），
  再把 viewport 调高到容得下整张卡（实测 1100×1800 够用），重新量一次 `boundingBox()` 确认整体落在视口内，最后才截。
  解除裁剪只发生在自己那个标签页里，拍完关掉即可。
- **切语言会让当前标签页重载**，切完要重新走一遍「设置 → 插件 → 插件配置」并重新展开四组。
- 卡片默认四组全收起。**必须展开再拍**，否则图里只有四个折叠头，等于没拍。
- 凭据行的徽标只有两态：「已配置密钥。/ 未配置密钥。」（官方「网页搜索」卡片同款）。
- **接口地址那一格默认是空的**：留空就是官方端点，填了才覆盖。图里出现 `https://api.deepseek.com` 说明截的是旧版默认值。
- 凭据输入框**应当是空的、且不置灰**（常态空框）：只读行不写占位符、不降透明度。图里若看到框内有灰字或整格发灰，说明截的是旧产物。
- **截图落盘一律给绝对路径**：tabbit 的 nodejs 运行器里 `process.env.TEMP` 是 `undefined`，相对路径会写进浏览器安装目录，事后很难找回来。
- **切完语言要重新走一遍「设置 → 插件 → 插件配置」并重新展开卡片**：页面重载会把卡片收回折叠态；卡片头是 `button[aria-expanded]`，分组头是 `div[role="button"][aria-expanded]`，两个都点齐才拍得到全卡。
- **截图前确认整张卡落在视口内**：`boundingBox()` 的 `top + height` 必须小于窗口高度，否则下半截是白的（元素框量得到、画不出来）。不够高就迭代加高 viewport。
- **`page.screenshot()` 会被浏览器运行时接管**：传了 `path` 也不写你指定的位置，而是落到它的 artifacts 目录，
  并在返回值里给你真实路径。**`locator.screenshot({ path })` 是原生 Playwright，照写不误** ——
  所以设置卡片那张直接落盘，左边栏那张（要裁一块区域，只能用 `page.screenshot`）得从 artifacts 里拷回来。
- **拍左边栏前先把 viewport 调回正常尺寸**：给设置卡片调高的 1100×1850 会让侧栏被拉宽，
  那时量出来的取景是错的。两张图用两套尺寸，中间记得切回去。
- 左边栏那张必然带进侧栏的**会话标题**（不是对话内容）—— 只要开了新会话就没有工作文字。
  连标题也不想露，就把取景压到浮层顶部以下，但那样就没有输入框了。
