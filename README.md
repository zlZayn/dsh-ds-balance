# ds-balance

在 DSH 的左边栏底部显示 DeepSeek 账户余额，并在设置里提供一个配置卡片。

## 能力

- 在侧栏底部常驻一个状态圆环加名称，点击展开浮层看余额明细。
- 折叠与展开共用同一个圆环，形状不随折叠变化。
- 浮层：余额、赠送 / 充值拆分、数据新鲜度与手动刷新。
- 币种与设置不一致时在浮层里说明，并提供一键改用（「去设置」按钮已就位，跳转尚未接线）。
- 设置卡片分四组、各自可折叠：连接 / 展示 / 阈值 / 刷新，默认只展开「连接」；组内有非法草稿时该组强制展开。
- 凭据字段带「已配置 / 未配置 / 已覆盖」徽标；「显示币种」是整行选择器（左文字 + 右胶囊）。
- 在「设置 → 插件 → DeepSeek 余额」里配置连接、展示币种、预警阈值与刷新节奏。
- 只按后端给的 `severity` 上色，阈值策略不在前端。

## 快速上手

```bash
npm install
npm run build
dsh plugin --profile web add .
```

最短可跑路径如上；挂载的完整步骤（确认 `dsh.profile.bundles` 里没有本插件、把 insert 行写进 profile 的 `cordis.patch.yml`）见 [AGENTS.md](AGENTS.md) 的「常用命令」。

修改宿主半边后必须重启 DSH；修改浏览器半边由客户端热更换入。

## 安全与边界

- 本阶段不连接任何真实接口，界面数据全部来自仓库内的 mock 模块。
- API Key 只经 DSH 的配置通道读写，插件不落盘、不外发。
