# postmortem/ — 规则层

继承根规则，见 [../../AGENTS.md](../../AGENTS.md)。

postmortem/ 特有约束：

- 只在 **subtle / systemic / costly 至少占一** 时才写；小失误一句话记进对应目录 `AGENTS.md` 的活跃坑即可。
- 骨架五条，越短越好：摘要（30 秒读完）/ 时间线（只记时间点与证据）/ 根因（一句话，直接命名机制）/
  防再犯（能落成代码或文档就落）/ 关联（决策记录与受影响的架构节）。
- **不追改**：写的是当时发生了什么；后来的变化写进新的复盘或决策记录。
- 复盘不是追责，目的是证据链 + 机制缺口 → 修复。
