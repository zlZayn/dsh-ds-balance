## 替代方案

- **设置页走 `settings.section`（任务书原稿）**：曝光度更高，但要自绘整个分区页与保存链路；维护者选择复用 `settings.plugin.item` 的现成卡片机制，故不采用。
- ⚠ **「启用左下角」关闭后注册空组件**：位置被本插件占住，别人无法复用；维护者选择完全不注册，故不采用。**（该配置项已整体删除，本条与 Q1.9 一并作废。）**
- **构建链跨仓 import harness 的 tsdown 预设**：官方明说该预设不对外发布，随 DSH 升级会断；故不采用。
- **宿主半边完全不做**：设置项无法持久化，阶段 5 的「所有配置项可编辑」验不过；故不采用。
- **依赖锚点跟随 `dsh-zhihu-search` 的 `^0.1.5-rc.2`**：本机宿主跑在 `0.1.6-alpha.1`，装不上；故不采用。

## 影响

- 设置页 UI 的形状由 `ui-settings-plugins` 的卡片机制决定：面板取「已服务命名空间 ∩ 已注册卡片」的交集，无回退。
- `package.json` 的 `dsh.client.inject` 必须包含 `@deepseek-ai/dsh-client-ui-settings-plugins`。
- ⚠ 左下角组件需要响应配置变化做动态注册 / 注销，注册逻辑不能只在 `apply` 里跑一次。**注册是常驻的：重注册会换 React key，导致整棵子树重挂、局部状态丢失。**
- 依赖锚点跟随 alpha 线，DSH 换线时需同步放宽并在 `AGENTS.md` 记一条债。

## 补充决策：第一版只显示余额（2026-09-17）

维护者追加：`todayUsage` 相关的三个元数据字段（`source` / `confidence` / `needsReview`）在 UI 侧全部砍掉。

理由（维护者原话意思）：这三个字段是给「今日已用」这个不稳定数字打的补丁；补丁越多说明底层越不稳。第一版不显示这个数字，就不需要这些补丁。

- 后端可以保留计算能力，UI 不接。
- **今日已用暂不做**，等后端双源估算跑稳后再评估。
- 左下角三个形态收敛为：

| 形态 | 内容 |
|---|---|
| 折叠 | 状态圆环 |
| ⚠ 展开 | 圆环 + 余额金额。**已被「补充决策：展开态只显示图标与标签」取代：展开态是圆环 + 文字标签，行内不显示金额。** |
| ⚠ 悬停浮层 | 余额、赠送、充值、刷新时间、刷新图标。**已被同一节取代：浮层由点击展开。** |

- **保留今日已用**：维护者判定数字不稳、补丁过多，故不采用。

## 补充决策：币种回退行为（2026-09-17）

设置页用下拉框选「显示币种」。选定币种在账户中不存在时，处理原则：**不静默、不惩罚、不偷偷改设置**。

- 显示账户里实际存在的币种，不显示 `--`（除非账户完全没有余额）。
- 加一个标记，告诉用户「这不是你选的币种」。
- ⚠ 悬停浮层说明原因，并提供一键修正。**浮层由点击展开（同上）。**
- 设置页下拉框保留用户选择，不自动改。

三种形态：

| 场景 | 展开态 |
|---|---|
| 选定币种存在 | `● ¥110.00` |
| 选定币种不存在，但有其他币种 | `● ¥110.00 ⓘ` |
| 账户完全没有余额 | `● -- ⓘ` |

浮层：说明一行（如「ⓘ 未找到 USD 余额，当前显示 CNY」）+ 两个动作 `[改用 CNY]` `[去设置]`。

⚠ 设置页：下拉框旁提示「ⓘ 当前账户无 USD 余额，实际显示 CNY」，下拉框本身不改用户选择。**设置卡片当前不渲染这条提示，币种不匹配的说明只在浮层里。**

边界：

- 选「自动」时永不出现标记。
- 一键修正后标记消失。
- 下一轮该币种到账后，标记自动消失并切回用户选定的币种。
- 账户完全没有余额：显示 `--` 加标记。

留给实现的自由空间：标记用哪个图标、标记放在金额后还是状态点旁、浮层文案措辞、一键修正的具体交互。

## 补充决策：展开态只显示图标与标签（2026-09-17）

维护者实机看过后改定。**取代任务书 3.2 的展开态内容。**

- 展开态 = 状态圆环 + 文字标签「DeepSeek 余额」，左对齐，与官方设置行、`dsh-usage-statistics-panel` 的条目同构。
- **行内不显示金额**；金额只在点击浮层里看。
- 浮层打开方式从「悬停即开」改成「点击展开」。
- 折叠态仍是同一个圆环，尺寸与展开态一致（不再有形状切换）。
- 币种不匹配的小标记保留在标签之后。

理由（维护者）：与原生条目保持同一形态。

代价：侧栏不再一眼看到余额，只剩状态色；金额需要一次点击。

### 替代方案

- **行尾只补状态词**（正常 / 预警 / 告急）：同样被否决。

## 补充决策：阶段 6 不重启宿主（2026-09-17）

勘察推翻早先假设。

- 当前 `dsh web`（PID 11464）就是承载本会话的进程，杀掉它会当场终止 Agent 自身。
- `patchReload: 'live'` 的 profile 会挂一个 watch-only HMR，监听 profile 的 `cordis.patch.yml` 与 `$DSH_HOME/cordis.patch.yml`；改文件即热挂载。
- 本机 web profile 实测 `patchReload` 为 `live`，其 `cordis.patch.yml` 含本插件的 insert 行。
- **挂载方式改为**：构建产物 → 把 insert 行写进 profile 的 `cordis.patch.yml` → 不重启，刷新浏览器验证。
- **回滚方式**：给该行加 `disabled: true`，热生效。
- 挂载前必须先产出 `lib/client.js`：缺它会让 `modules` fiber 失败，而 `modules` 在必需启动清单里，宿主会拒绝启动。
