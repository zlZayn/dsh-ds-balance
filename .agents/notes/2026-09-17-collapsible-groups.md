# 决策：设置卡片改可折叠分组（2026-09-17）

已实施。

## 问题

配置卡片四组字段纵向排开，改一个值要滚到卡片底部才够得着保存按钮。

## 决策

四组各自可折叠，用官方原语 `DisclosureRow`（`@deepseek-ai/dsh-client-ui-primitives`）承载。

- **各项独立展开，不做手风琴**：官方 `PluginCard.tsx:8-9` 的注释明确说多项可同时展开是刻意的。
- 默认只展开「连接」组，展示 / 阈值 / 刷新三组收起，卡片一打开就是短的。
- **组里有非法草稿时该组强制展开**：非法会禁用保存，而 footer 只给一句「请检查标红的字段」；若那一组收起着，提示就指向看不见的东西。
- 折叠状态不持久化（官方仅 `ui-workspace` 一处先例，不值当）。

### 从原语继承的约束

- 展开时分组图标被原语自己的 chevron 顶掉，图标只在收起态可见。
- 条件渲染，**没有展开动画**（官方自己也没有）。
- 标题行固定 `24px`，过长会被硬裁、无省略号。

## 替代方案

- **自绘折叠头**：样式规矩要求「先复用控件，不要另造一个」，故不采用。
- **做手风琴（同时只开一组）**：官方是先例存在但非默认；卡片只有四组，强制互斥反而增加操作，故不采用。
- **折叠状态持久化到 Host 设置文档**：折叠位图不属于用户配置语义；官方正解是 `defineStore({ persist })` 存 localStorage，但全仓仅一处先例，v1 不做。
- **把保存按钮改成吸底**：会偏离官方 `PluginCard` 的既定形态，故不采用。

## 影响

- 卡片默认高度大幅下降。
- 首次使用需要展开冷门分组；默认展开的「连接」组覆盖最常见的配置路径。
- 收起态不放摘要（原语支持 `collapsedContent`，但会让收起行变长，与目标相反）。
