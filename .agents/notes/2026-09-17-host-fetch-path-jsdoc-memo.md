# 备忘：宿主 `ConnectionFetchRoute.path` 的 JSDoc 与实现矛盾（2026-09-17）

只记录事实与我们的处置，不改宿主、不提 issue。

## 事实

- JSDoc 写「Absolute path below `/api`」。
- 实现按**完整 pathname 精确匹配**，并要求 `path` **含 `/api` 前缀**（不满足注册即抛）。
- 测试断言 `'/outside'` 抛错。

**以实现与测试为准。**

## 我们的处置

- 注册时写死精确路径 `/api/v1/balance` 等，**不带尾随斜杠，不依赖任何归一化**。
- 匹配是 Map 精确键匹配，无大小写或斜杠归一化 —— 所以路径里出现的每一个字符都是契约。

## 影响

- 若宿主将来改动 path 匹配规则，我们的路由会静默失效。
- 挂载验证时必须逐个确认端点可达，不能只看「注册没抛错」。
