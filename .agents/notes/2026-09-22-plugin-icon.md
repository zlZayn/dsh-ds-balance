# 插件图标：就是那条环

**类型**：决策记录（问题 / 决策 / 替代方案 / 影响）。
**取代**：[2026-09-22-plugin-display-metadata.md](2026-09-22-plugin-display-metadata.md) 的「替代方案 2（不加图标）」——
那一轮按「没有现成的自包含图形资产，硬造一个等于替维护者做设计决定」没加；维护者随后拍板要加，于是有了这一条。

## 问题

插件页上的卡片与详情页那一格一直显示宿主的默认图形。要做成什么样？
用户原话：「设计一个和左下角圈一样（**橙色**，大概**消耗了 70%** 的状态）的自己创建一个 svg 存起来就行」。

## 事实（实测，出处给到文件）

- **宿主按图片渲染它**：`packages/boot/app-boot/src/package-meta.ts` 的 `iconOf()` 把文件读成 base64 data URL。
  所以 `currentColor`、外链图片、外部 CSS、字体**全都无效**，必须自包含；颜色只能写死。
- **官方配方**（`packages/experimental/agent-team-profile/icon.svg` 等）：`width/height=36` + `viewBox="0 0 36 36"`
  + 根上 `fill="none"`，图形本体 18–20 见方、**四周留 8–9**。
- **环自己的几何**（[PercentRing.tsx](../../src/client/sidebar/PercentRing.tsx)）：`VIEW=16`、`STROKE=1`、
  `RING_INSET=1`、`RADIUS=6.5`、`CENTER=8`，墨迹外径 14；弧用 `strokeDasharray` + `rotate(-90 8 8)`
  （接缝在 12 点）、**圆头线帽**。
- **warn 档的颜色**：`--dsw-alias-state-warn-primary` = `--dsw-static-amber-500` = `rgb(245, 158, 11)` = `#F59E0B`，
  宿主 `ui-theme/src/styles/design-platform.css` 的**亮、暗两块表里逐字相同**。
- **70% 落在哪一档**：默认阈值（[config.ts](../../src/config.ts)）CNY 10/5、USD 2/1 ⇒ 告急 = 预警的 50%；
  `severityOf()` 判「余额 ≤ 告急 → critical，≤ 预警 → warn」⇒ 弧长 70% 的余额在告急线之上、预警线之下，
  **正是 `warn`**（`dotStateOf('warn') = 'warning'`）。
- **轨道的颜色是跟随主题的**：环的轨道取 `--dsw-alias-border-l3` —— 亮 `rgba(0,0,0,.12)`、暗 `rgba(255,255,255,.16)`
  （`design-platform.css` 的两块表），**静态资源烘不了主题**。宿主的中性阶是亮暗同值的：
  `--dsw-static-neutral-500` = `rgb(127,130,135)`。把那个灰按 45% 不透明度合成上去：白底 ≈ `rgb(197,199,201)`
  （真轨道 `rgb(224,224,224)`）、深色底 ≈ `rgb(86,88,92)`（真轨道 `rgb(85,86,88)`，几乎逐值相同）。
- **宿主渲染尺寸**（`ui-plugin-manager/src/client/PluginManagerPage.tsx`）：`CARD_ARTWORK_SIZE = 36`
  （卡片 + 详情页 + 详情页里的行）、`ROW_ARTWORK_SIZE = 30`（bundle 详情里那一行）。
- 官方校验器 `scripts/verify-package-meta.ts` 检查 icon 的声明、可达与**发布覆盖**；它只扫官方仓。

## 决策

1. **包根新增 [icon.svg](../../icon.svg)**：`width/height=36` + `viewBox="0 0 36 36"` + `fill="none"`，
   **几何一个字都没另起** —— 环的那套（`cx/cy=8`、`r=6.5`、`stroke-width=1`、`rotate(-90 8 8)`）整组套
   `translate(18 18) scale(9/7) translate(-8 -8)`：墨迹外径 14 → **18**，外接框 **9–27**，四周各留 **9**。
2. **颜色写死 `#F59E0B`** —— 它就是环在 `warning` 档画的颜色，且官方在亮暗两块表里给的是同一个值（事实第 4 条）。
3. **弧长 70%**：`stroke-dasharray="28.588 40.841"`，与组件在 `ratio=0.7` 时算出来的**逐字相同**
   （`2π × 6.5 = 40.841`）。线帽照环用**圆头**：加上两端的半圆，可见弧长约 260.8°（72.5%）。
4. **带上轨道圈**：与环同几何（同一个 `r` / 笔画）、整圈不设 dasharray，颜色写死 `#7F8287`
   （= 宿主 `--dsw-static-neutral-500`，亮暗同值）加 `stroke-opacity="0.45"` —— 合成结果落在两种主题各自的
   轨道观感上（事实最后两条），所以「烘不了主题」这件事在这里有解。**第一版按可读性取舍没画，维护者要求补上**
   （见替代方案 3）。
5. **SVG 注释里不写那两个连字符开头的 token 原名**：第一版写了，而 XML 规范**不许注释里出现连续两个连字符**，
   文件因此不是良构 XML —— 浏览器当图片解析直接失败，插件页静默回落成默认图形（宿主不校验，它只编 data URL）。
   现在红线里有一条良构检查（注释规则 + 标签成对 + 属性带引号）守着。
6. **`package.json` 顶层 `"icon": "./icon.svg"`，`files` 收录 `icon.svg`**；断言按宿主 `iconOf()` 的判据补齐
   （相对路径 / 扩展名 / 留在清单目录内 / 普通文件 / ≤256 KiB / 进包），红线钉住它与圆环同形。

## 替代方案（试过或想过，为什么不选）

1. **沿用官方橙 `#F2AF63`**。不选：我们的环**不认**这个颜色 —— 它由 `severity` 驱动，warn 档取值是 amber-500。
   图标既然画的是那条环，颜色就该是它画出来的那个；顺带算下来 `#F2AF63` 在**亮底上更糊**
   （对比度 1.89:1，我们是 2.15:1；暗底 6.39:1，我们是 5.63:1）。
2. **画满环或换别的弧长**。不选：用户要的是「消耗了 70%」这个状态；满环会读成 100%，
   而 70% 正好落在 warn 档（事实第 5 条）。
3. **不画轨道圈**（**第一版就是这么做的，已被维护者否掉**）。当时的理由是「跟随主题的半透明色烘不进来，
   换成中性灰等于给 18px 的图加第二种颜色」。**理由站不住**：用户说的「和左下角圈一样」本来就包含那一圈，
   少了它图标只是「一段弧」而不是那条环；而烘焙色有解 —— 决策 4 那条（中性灰 + 不透明度）在两种主题下
   都落在真轨道附近。教训：拿「资源形态的限制」去否决「用户明说的形状特征」，先想想有没有折中值。
4. **用 `currentColor` 或 CSS 变量**。不可行：宿主按图片渲染（事实第 1 条）。
5. **在 48 的画布上画**（卡片那一格是 48×48）。不选：官方配方是 36 画布 + 四周 8–9，而宿主对
   36-viewBox 的图形**正好按 36px 渲染**（`CARD_ARTWORK_SIZE`）—— 画布跟着官方走，渲染就是 1:1，不用缩放。

## 影响

- 插件页的卡片、详情页与行上会出现那条环本身：一圈淡轨道 + 七成橙弧（图形 18px、笔画 1.286px）。
- **外接框**：轨道是整圈，所以墨迹外接框**四周都是 9–27**（留白 9/9/9/9，落在官方配方 8–9 里）——
  不画轨道时左边那侧只到 9.409（七成弧够不着 9 点方向），补上轨道之后这个不对称也一起没了。
- **可读性实测**：36px 渲染时图形 18px / 笔画 1.286px；30px 渲染时 15px / 1.071px ——
  与左边栏那条环（16px 下笔画 1.000px）**同一档**，不是靠放大才看得见。
  轨道是设计里最淡的一笔（合成后约 1.3–1.6:1），在两种主题上都看得出是「一圈」而不是缺一块。
- **门面图**：图标会进 `settings-card*.png` 与 `settings-cards-position*.png` 四张（卡片与详情页都画它）——
  那四张本来就因展示元数据待重拍，现在多一条理由。
- **多了一个会静默坏的面**：`icon` 声明错、没进 `files`、或超过 256 KiB，插件页只会静默落回默认图。
  断言在 [check-release.mjs](../../scripts/check-release.mjs)（照 `iconOf()` 的判据）与红线「插件图标」。
